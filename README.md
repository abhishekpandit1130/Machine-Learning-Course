# Machine Learning Projects

This repository contains four fundamental machine learning projects covering classification and regression tasks.

## 📁 Projects

### a. Digit Recognition using CNN (MNIST Dataset)
- **Description**: Implemented a Convolutional Neural Network to recognize handwritten digits (0-9)
- **Dataset**: MNIST (70,000 grayscale images)
- **Model**: CNN with Conv2D, MaxPooling, Dense layers
- **Accuracy**: ~99.2% on test set
- **Output**: Saved model (`mnist_cnn.h5`) and predictions CSV

### b. House Price Prediction using Linear Regression
- **Description**: Predict house prices from square footage using Linear Regression
- **Approaches**: Scikit-Learn LinearRegression vs custom Gradient Descent
- **Results**: Both methods achieved ~99% accuracy (R² score)
- **Features**: Synthetic dataset with house sizes (500-3500 sq ft)

### c. Decision Tree using Iris Dataset
- **Description**: Classification of iris flowers into three species using Decision Tree
- **Dataset**: Iris dataset (150 samples, 4 features)
- **Model**: Decision Tree Classifier
- **Features**: Sepal length, sepal width, petal length, petal width
- **Classes**: Setosa, Versicolor, Virginica

### d. KNN using Iris Dataset
- **Description**: K-Nearest Neighbors classification on Iris dataset
- **Dataset**: Iris dataset (150 samples)
- **Model**: KNN Classifier with optimal k value
- **Features**: Same as Decision Tree project
- **Classes**: Setosa, Versicolor, Virginica
